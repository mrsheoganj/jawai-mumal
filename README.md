> **Jawai Mumal** is an authentic 5-star boutique hospitality web platform and management portal situated in Rajasthan's famed leopard country (Jawai Bandh, Sumerpur, Pali).

---

## 🌟 The Three Core Pillars

1. **🏨 Hotel Stays**
   - Luxury Tented Suites, Granite Cliff Villas, and Private Pavilions.
   - Interactive booking engine with dynamic pricing, night calculation, and room amenity highlights.
2. **🍽️ Restro & Dining**
   - The Mumal Rasoi & Fireside Bush Dinners on ancient volcanic granite kopjes.
   - Interactive filterable digital menu with Veg / Non-Veg diet indicators and spice levels.
   - Table reservation system.
3. **🐆 Jawai Safari Expeditions**
   - Morning & Evening open-top 4x4 Gypsy leopard tracking drives.
   - Licensed indigenous Rabari master trackers with a 98% sighting record.
   - Jawai Dam wetland birdwatching (flamingos, cranes, marsh crocodiles).

---

## 🔐 Administrative Management Portal

- **Admin Login:** `/admin/login.php` (or `/admin/login.html` on GitHub Pages)
- **Default Username:** `admin`
- **Default Password:** `admin123`

### Operational Modules:
- **📊 Operations Dashboard:** Gross sanctuary revenue, stay metrics, daily safari departures, and dining covers.
- **🏨 Hotel & Room Inventory:** Add/edit room suites, toggle sold-out dates, and update check-in / check-out states.
- **🍽️ Restro & Menu Manager:** Add new dishes, manage prices, real-time 86'd out-of-stock toggles, and table seating.
- **🐆 Jawai Safari Fleet:** Dispatch 4x4 Gypsies (Gypsy #1 through #4) and allocate master trackers to departures.
- **💬 VIP Inquiries:** Review and resolve guest requests and royal wedding inquiries.
- **⚙️ Resort Settings:** Update phone numbers, WhatsApp, tax percentage, and export database backups.

## 🚀 Deployment Options

### Option 1: GitHub Pages (Live Static Preview)
This repository is configured to host directly on GitHub Pages at:
**[https://prashantdesign.github.io/Jawai-Mumal/](https://prashantdesign.github.io/Jawai-Mumal/)**

### Option 2: Hostinger (Production PHP + MySQL)
1. Upload all files into Hostinger's **`public_html`**.
2. Create a MySQL Database in Hostinger hPanel and import **`database.sql`** via phpMyAdmin.
3. Enter database credentials in **`config.php`**.
4. Full deployment guide in [README_HOSTINGER.md](README_HOSTINGER.md).
